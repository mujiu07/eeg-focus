# 专注小蛙 · 梦境池塘 (Brain-Focusing Game MVP)

> 脑电特征驱动的游戏机制演示（教学用，不构成注意力评估）

一款儿童友好的脑电游戏机制演示小游戏 MVP。核心机制：**脑电信号 → 脑波分数 → 个人基线 → "蓄力→跳出"**——只有保持专注才能推动游戏角色前进，把"专注"变成完成游戏动作的必要条件。面向 ADHD 儿童的注意力训练应用属于**长期方向**，本 MVP 不声称训练或诊断效果。

基于 PRD-brain-focusing-game-MVP.md 再造，专注引擎由 PhysioNet EEGMAT 数据集（心算专注 vs 背景放松，36 名被试真实脑电）训练而来；接入 Xmuse 脑电波仪时自动切换 4/6 通道频段指标。

## 功能亮点

- **三种信号源**：EDF 真实数据回放 / 手动滑块 / **Xmuse 脑电波仪真机（OSC/UDP，已接入）**
- **心率辅助信号（可选，仅 macOS）**：接入 AirPods Pro 3 心率（经 `hrd` 读取 iPhone 训练界面），校准静息心率后按权重融合进专注分；未接入时保持纯 EEG
- **仅心率模式（仅 macOS）**：没有脑电设备也能玩，信号源选「❤️ 仅心率」，专注指数完全由心率驱动（静息 = 0.5，降心率涨分）
- **全站天空模式**：黎明 / 白天 / 傍晚 / 黑夜 / 跟随系统时间（按日出日落自动切换），跨页保存
- **动态梦境池塘首页**：青蛙在荷叶间跳跃、鱼群游弋、水花与晨昏光影，随天空时段变色；游戏画面共用同一套天空色板，四档主题与首页保持一致
- **黑胶唱片机背景音乐**：服务端代理网易云歌单，全站共享播放状态，跨页续播、随时暂停
- **游戏时长可选**：1 / 3 / 5 / 10 分钟或 1–60 分钟自定义（默认 3 分钟）
- **报告页"给家长的话"**：自动生成本局表现概述、训练建议与免责声明，附庆祝卡片
- **校准基线 1 小时有效**：刷新/关闭页面无需重新校准，首页显示剩余时间
- **隐私优先**：脑电数据全程本地处理，仅可选背景音乐需要联网

## 快速启动

### macOS

双击 **`start.command`** 即可。首次运行会自动创建 `.venv` 并安装依赖（需联网，1–3 分钟），之后每次双击直接启动并打开页面。

### Windows

双击 **`start.bat`** 即可（内部调用 `start.ps1`，不需要改 PowerShell 执行策略）。

### 启动脚本做了什么

- 已在运行时不会重复启动，只打开页面
- 服务就绪后自动打开 <http://127.0.0.1:8000>
- 关闭终端窗口即停止服务
- **心率默认不启用**：需要时在校准页「心率辅助」里手动选择；该功能仅 macOS 可用

### 手动启动（排查用）

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.server:app --host 127.0.0.1 --port 8000
```

> **无需数据集也能体验**：不下载 EDF 样本时，游戏仍可运行（`manual` 手动源）；执行 `scripts/preprocess.py` + `scripts/train.py` 可重建模型。
>
> 需要真实脑电回放样本时：`bash scripts/download_data.sh`（一次性，约 183MB）。

已有 EEGMAT 样本时，将放松段 `SubjectNN_1.edf` 和同一被试的心算段
`SubjectNN_2.edf` 放在 `data/eegmat/`，或在启动前设置
`EEG_FOCUS_EDF_DIR` 指向样本目录。校准页会检查是否有完整的回放配对。


## 完整用户旅程（演示）

1. **首页** → 选择天空模式（可选）→ 点击"进入脑电校准"（或直接"开始游戏"，首次会引导先校准）
2. **校准页**：选择演示信号源（默认：真实脑电数据回放·放松段；真机可选 Xmuse 并填写 OSC 端口），点击"开始校准"，跟着呼吸球放松 20 秒
   - 服务端实时计算脑波分数（模型预测概率，EMA 平滑，教学映射）
   - 结束后生成**个人基线**（校准期间脑波分数中位数，教学阈值）
   - 基线本地保存并**1 小时内有效**：期间刷新/关闭页面无需重新校准，超过 1 小时需重新校准
3. **游戏页**：同一被试的**专注段**脑电数据驱动（或手动模式拖动滑块）
   - 首页弹出**时长选择**，确认后进入游戏（1/3/5/10 分钟或自定义）
   - 专注指数 ≥ 基线 → 蓄力条上升 → 蓄满 → 青蛙跳向下一片荷叶（+1 分）
   - 专注指数 < 基线 → 蓄力条回落，青蛙"跳不动"
   - 超过 3 秒无有效数据 → 自动暂停蓄力，避免旧分数继续驱动
4. **报告页**：庆祝卡片、游戏成绩、脑波分数曲线（教学映射）、高于基线时间占比、有效数据占比，以及自动生成的"给家长的话"
5. **开发者页**：模型评估报告、信号源切换（72 个 EDF 文件 / 手动 / Xmuse OSC）、实时监视

## 三种信号源（信号源抽象层）

| 模式 | 说明 | 用途 |
|---|---|---|
| `replay` | EDF 真实数据回放（默认） | 演示"真实脑电驱动"：放松段低专注、心算段高专注，端到端闭环可复现 |
| `manual` | 滑块直接控制专注度 | 无数据环境/机制演示：把滑块拉到右侧青蛙一直跳，拉到左侧就跳不动 |
| `hardware` | **Xmuse 脑电波仪（OSC/UDP）** | 真机驱动：Xmuse Direct / Lab 通过 UDP 推送脑电，服务端 2s 出窗 |

### Xmuse 真机接入速查

- 默认同时监听 UDP **7000**（Xmuse Direct 默认）与 **8000**（官方示例默认），地址匹配 `/eeg`、`/8000/eeg`、`/muse/eeg` 等以 `/eeg` 结尾的路径
- 在 Xmuse Direct 中把 OSC 输出目标设为 `127.0.0.1`，端口与校准页/环境变量填写的一致（默认 `7000,8000`）
- 先验证推流是否进来（同时监听 7000/8000）：

  ```powershell
  .\.venv-win\Scripts\python.exe scripts\xmuse_osc_probe.py
  ```
- 网页服务是 **TCP 8000**、OSC 是 **UDP 8000**，协议不同，可同时占用
- 默认端口的证据链与变更守则见 [`docs/xmuse-hardware-integration.md`](docs/xmuse-hardware-integration.md) §2.3.1；修改默认端口必须附真机探针日志，不能只凭单个官方示例
- 可选环境变量：`XMUSE_OSC_HOST` / `XMUSE_OSC_PORTS` / `XMUSE_OSC_FS`（默认 256）/ `XMUSE_OSC_CHANNELS`（默认自动）
- 4/6 通道数据无法输入 21 通道 EEGMAT 模型，会自动改用 `beta / (theta + alpha)` 频段指标映射到 0–1（仅游戏机制相对变化，不是临床分数）
- 详细排障与协议说明见 `docs/xmuse-hardware-integration.md`

## 脑波分数引擎（教学映射）

- 特征：2s 窗口 × 21 通道 × 11 特征（5 频段绝对/相对功率 + θ/β 比）
  - 注：当前为混合生理通道模型（含 A2-A1 参考导联与 ECG，非纯 EEG）；重建纯 EEG 最小基线并对比移除前后结果，属于后续工作，未完成前不得把该模型描述为"EEG 专用"
- 模型：LogisticRegression（`scripts/train.py`，LOSO 交叉验证，按被试划分）
  - 准确率 0.729 / 平衡准确率 0.640 / AUC 0.731（团队自述指标，需核对正类与逐被试结果）
  - 分数语义：**"在该数据协议下更接近心算任务的模型分数"**（EEGMAT 为背景/心算任务数据，非通用专注量表，也不是 ADHD 诊断或训练数据）
- **4/6 通道设备回退**：当输入通道数与模型维度不匹配（如 Xmuse）时，自动使用相对频段功率比 `beta / (theta + alpha)`，经 sigmoid 映射到 0..1，再走同一套 EMA 平滑与基线逻辑
- 验证示例：放松段脑波分数均值 ≈ 0.01，心算段 ≈ 0.57 → 区分度明显（教学演示用途）

> **研究边界**：本产品不证明、也不声称能够测量注意力水平或改善 ADHD 症状。神经反馈训练的有效性与适用人群仍处于研究阶段（参见 NIMH 相关说明）。界面中的分数一律表述为"脑波分数（教学映射）"。

## 背景音乐（可选，网易云歌单代理）

- 全站左下角黑胶唱片机：落针播放 / 抬针暂停 / 左右箭头切歌，播放进度跨页保留
- 服务端接口：`GET /api/music/playlist`（歌单）、`GET /api/music/url/{track_id}`（单曲直链，缓存 8 分钟）
- 未登录时只能拿到歌单前 10 首，登录后可取全量；登录态可通过环境变量 `NCM_COOKIE` 或本机文件 `data/music_cookie.txt` 提供
- 获取登录 cookie：运行 `python scripts/ncm_login.py`（可选，非必需）
- **凭据安全**：`data/music_cookie.txt`、`*.cookie` 与 `.env` 均已加入 `.gitignore`，请勿提交
- 歌单 ID 可用 `NCM_PLAYLIST_ID` 覆盖；音乐不可用（断网/版权限制）不影响游戏

## 隐私声明

- **脑电数据处理全部在本地**：不上传任何云端，可完全断网运行（回放/手动/真机均如此）
- 前端零外部静态资源；接口仅监听 `127.0.0.1`
- **唯一联网功能是可选背景音乐**：服务端会访问 `music.163.com` 拉取公开歌单与播放直链，不发送任何脑电/会话数据；不使用音乐时无该请求
- 会话记录仅落盘本机 `outputs/sessions/`（不进入本仓库）
- 详见 `docs/usage-and-privacy.md`（含数据清单与清理方法）

## 关键技术决策

- **数据本地**：脑电数据仅存本地，无账号体系（符合 PRD：MVP 不上传、儿童敏感数据）
- **零构建前端**：原生 HTML/CSS/JS + Canvas，免费部署、任意静态托管均可
- **SSE 推流**：服务端按 0.5s 步长推专注指数，前端 rAF 游戏循环消费
- **校准即基线**：校准期专注指数中位数作为个人基线阈值（P0 需求），1 小时有效
- **硬件可回退**：通道数与模型不匹配时自动改用频段指标，Xmuse 无需重训模型即可驱动游戏
- **单一硬件会话**：新建硬件会话会自动结束旧会话，避免 UDP 7000/8000 端口争抢
