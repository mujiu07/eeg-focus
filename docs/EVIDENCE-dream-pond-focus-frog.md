### 1.3 模型验证（离线）

来源：`outputs/train_report.md`（PhysioNet EEGMAT，36 名被试，4338 个 2 s 窗口，LOSO）

| 指标 | LogisticRegression（当前模型） | RandomForest（对照） |
|---|---|---|
| 准确率 | 0.7291 | 0.7467 |
| 平衡准确率 | 0.6399 | 0.5597 |
| F1（专注类） | 0.4642 | 0.2619 |
| ROC-AUC | 0.7312 | 0.7446 |

- 逐被试波动明显：最高 Subject28 0.926，最低 Subject02 0.320 → 不能把单次分数当稳定能力指标
- 混淆矩阵：放松 2654 正确 / 568 误判；专注 509 正确 / 607 误判 → 召回偏低，符合"宁可少判专注"的产品取向

## 5. Demo Day 材料

### 5.1 演示叙事（5 分钟）

1. **问题**（40 s）：孩子走神时自己不知道；多数产品只显示分数
2. **机制**（60 s）：专注 → 蓄力 → 起跳；不专注就跳不动
3. **现场演示**（120 s）：
   - 打开首页，切换天空模式
   - 进校准，40 s 完成基线
   - 玩 1 分钟：先专注起跳，再故意走神看蓄力回落
   - 打开报告：曲线、起跳时刻、给家长的话
   - 导出一份 PDF
4. **成长系统**（40 s）：签到、成就、商城买一件装扮并穿上
5. **边界与证据**（40 s）：脑电不出本机；模型指标与局限；下一步是真实用户验证

### 5.2 演示前检查清单

- [ ] `start.bat` / `start.command` 可一键启动
- [ ] 端口 8000 未被占用
- [ ] 有可用 EDF 配对（或开发者模式无设备试玩）
- [ ] 浏览器缩放 100%，关闭无关标签
- [ ] 导出依赖已安装（PDF/Excel/Word 各试一次）
- [ ] 关闭音乐时无外网请求（隐私演示）
- [ ] 准备一份已完成的报告作为兜底

### 5.3 评审要点

- 机制是否真的把"专注"变成必要条件（不是装饰）
- 是否诚实标注非诊断、非疗效
- 文档是否能支撑复现与追溯
- AI 使用是否有记录、有验证
