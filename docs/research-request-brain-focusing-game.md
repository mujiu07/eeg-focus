## 深度研究请求：Brain-Focusing Game

> 版本：与代码 v1.4.15 对齐（2026-11-17）
> 说明：本文是**研究请求**（问题清单），不是研究结果；研究结果请另存为 `docs/research-brain-focusing-game.md`，并在开头标注研究状态。
> 当前项目已实现 P0 与成长系统（积分/签到/成就/商城/装扮）、Xmuse 真机接入、PDF/Excel/Word 导出，研究问题已按现状补充到第 8–10 条。

<context>
我是非技术背景的创始人，正在构建一款 ADHD 儿童注意力训练工具。要解决的问题：ADHD 儿童注意力维持困难、缺乏对自身专注状态的觉察，传统训练枯燥易脱落。核心功能：作为注意力训练工具，把专注度指数通过个人基线阈值映射为游戏反馈，让"专注"可视化、可操作。目标用户：ADHD 儿童（直接用户），家长和康复/教育人员（间接使用者）。我需要面向初学者的研究，并给出可执行的见解。

当前 MVP（v1.4.15）已在本机跑通：EDF 回放 / 手动 / Xmuse 脑电 / 仅心率四种信号源，校准后建立个人基线，专注达标才能"蓄力→起跳"；报告可导出 PDF/Excel/Word；另有本地积分、签到、成就、商城与装扮。产品无账号、脑电数据不出本机。
</context>

<instructions>
### 需要回答的关键问题：
1. 有哪些类似应用？它们具备哪些功能？
2. 用户喜欢/讨厌现有解决方案的哪些方面？
3. 构建 MVP 的最简单方式是什么？
4. 最适合此项目的无代码/低代码工具有哪些？
5. 类似应用如何盈利？我可以现实地收取多少费用？
6. 哪些 AI 工具或 API 可以加速开发或使 MVP 更具差异化？
7. 如果 AI 属于产品的一部分，它可以读取哪些数据、执行哪些操作，以及需要哪些审批/评估保障措施？
8. **儿童游戏化留存与伦理**：积分、签到、成就、装扮、商城这类机制在 6–12 岁儿童产品中，哪些做法有证据支持能提升坚持度，哪些容易滑向过度激励或消费诱导？家长对"每日签到 / 连续打卡"的接受度如何？
9. **报告与家长沟通**：面向家长的训练报告应包含哪些指标与措辞，才能既传达变化又不制造"疗效"暗示？PDF/Excel/Word 导出对家长/康复人员的实际使用价值如何？
10. **心率作为辅助信号**：用静息心率变化辅助判断放松/专注，有哪些公开证据与边界？在只有 4 通道消费级脑电（Xmuse）时，频段指标与心率融合的合理权重与验证方法是什么？
</instructions>
