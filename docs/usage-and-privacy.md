# 专注小蛙 · 梦境池塘 — 使用与隐私说明

> 项目：`eeg-focus/`（脑波专注游戏 MVP）
> 版本：v1.4.16（2026-11-19）
> 隐私承诺：**脑电数据全部在本地处理，不上传任何脑电数据**——本承诺基于代码实现，详见第 6 节。

---

## 1. 这是什么

"专注小蛙 · 梦境池塘"是一款儿童友好的脑波专注游戏（纯本地 Web）：

- 戴上脑电设备（或使用 EDF 数据回放 / 手动模拟 / 仅心率），系统实时计算"专注度"
- 专注度达到个人基线时，池塘里的小蛙才能蓄力、跳出，落到下一片荷叶
- 附带：校准、训练报告与导出、成就、积分商城、装扮、每日签到、天空主题与可选背景音乐

四种信号源（`app/sources.py`）：

| 信号源 | 说明 | 用途 |
|---|---|---|
| `replay` | 回放本机配对 EDF 脑电数据 | 默认演示、无设备体验 |
| `manual` | 滑块手动调整专注度 | 演示/测试 |
| `hardware` | Xmuse 脑电波仪（OSC/UDP 真机接入） | 真实脑电驱动 |
| `heart` | 仅心率（AirPods Pro 3，仅 macOS） | 没有脑电设备也能玩 |

> 心率辅助（可选）可在脑电之外按权重融合；仅心率模式下专注指数完全由心率驱动，页面对此有明确标注。

## 2. 安装与启动

### 2.1 环境要求

- Windows / macOS / Linux，Python 3.10+
- 浏览器（Chrome / Edge / Safari 均可，无需任何插件）
- 使用真机时另需：Xmuse 设备 + Xmuse Direct（或 Xmuse Lab）软件
- 使用心率时另需：macOS + AirPods Pro 3 + `hrd` 工具（非必需）

### 2.2 一键启动（推荐）

- **macOS**：双击 `start.command`
- **Windows**：双击 `start.bat`（内部调用 `start.ps1`，无需改执行策略）

首次运行会自动创建 `.venv` / `.venv-win` 并安装依赖（需联网，1–3 分钟）；之后每次双击直接启动并打开 <http://127.0.0.1:8000>。已在运行时不会重复启动，只打开页面。

### 2.3 手动启动（排查用）

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.server:app --host 127.0.0.1 --port 8000
```

浏览器打开 **http://127.0.0.1:8000** 即可进入首页。

> **无需设备或数据集也能体验**：首页按 `↑ ↑ ↓ ↓ ← → ← → B A B A` 进入开发者模式，选择「无设备试玩 · 1 分钟」。

## 3. 使用流程

### 3.1 首页（index.html）
- **天空模式**：黎明 / 白天 / 傍晚 / 黑夜 / 跟随系统时间；选择保存在本机浏览器并对全站生效，游戏画面的天空、日月星、云、远山与水面会同步渐变切换
- 首页展示动态池塘（青蛙跳跃、鱼群、水花与晨昏光影）与玩法说明
- 右侧四个入口：**每日签到**、**成就**、**商城**、**装扮**
- 点击"进入脑电校准"建立基线；点击"开始游戏"选择本局时长
- **游戏时长**：1 / 3 / 5 / 10 分钟，或自定义 1–60 分钟（默认 3 分钟）
- "最近训练"展示最近几局的校准基线
- 左下角黑胶唱片机可播放/暂停背景音乐（见 3.7）

### 3.2 校准（calibrate.html）
- 默认 40 秒：前 20 秒安静放松，后 20 秒跟着心算引导做题（也可开 60 秒引导视频，最长 600 秒）
- 可选信号源：EDF 回放 / 手动 / Xmuse 脑电波仪 / 仅心率；选 Xmuse 时填写 OSC 端口（默认 7000,8000）
- 心率辅助默认关闭，只有本次显式选择才启用（仅 macOS）
- 基线保存在浏览器本地（`localStorage`），**1 小时内有效**：期间刷新、关闭标签页或浏览器都无需重新校准
- 超过 1 小时后基线自动失效，进入游戏会引导回到校准页重新校准
- 校准失败（信号中断 / 有效帧不足）会明确提示，不会写入伪基线

### 3.3 游戏（game.html）
- 开始后每 0.5 秒收到一帧专注度（`focus` 0–1），画面随专注度变化
- 顶部显示剩余时间、得分与专注状态灯；持续走神时底部给出提示
- 专注度高于个人专注线（50 分）→ 蓄力上升；短暂走神进度保持，连续低于阈值超过 1.5 秒才缓慢衰减；信号中断时蓄力、衰减与计时都暂停
- 蓄力进入金色区间后，蓄力条进入**子弹时间**并慢速穿过；在约 2.5 秒窗口内点击池塘或按空格可**完美起跳**，获得 20–100 分（进入时的蓄力越快，潜在得分越高）
- 每轮只有一个金色区域；错过窗口会立即普通跳跃、当轮 0 分，不会补发第二个区域，也不等待蓄满
- 首次上手会弹出一张玩法卡片，讲清"金色区间会慢下来，抓住时机点击"
- 结束进入结算卡片：显示本局表现分与"本局积分 +N"（积分按表现分 30:1 折算），有新成就时先播成就解锁动画；随后可查看报告

### 3.4 报告（report.html）
- 展示本次会话的专注度趋势、最高分、高于基线占比、有效数据占比
- 曲线可拖动回看，或四倍速播放；新记录能定位到完美起跳与普通跳跃的时刻
- 顶部庆祝卡片（撒花与鼓励语）
- **给家长的话**：根据本局数据自动生成表现概述、训练建议与免责声明；无基线或有效数据不足时会明确提示
- **导出这份报告**（本机生成，不经过云端）：
  - PDF：A4 排版 + 专注曲线，适合打印或直接发给家长
  - Excel（`.xlsx`）：概览 + 逐点曲线 + 起跳事件 + 折线图
  - Word（`.docx`）：概览表 + 给家长的话，适合先改措辞再发
  - CSV / JSON：逐点数据 / 原始报告
- 数据来自本地落盘的会话 JSON（见 6.2）

### 3.5 开发者页（dev.html）
- 面向开发者：创建会话、查看实时 SSE 帧、监视原始值
- 支持切换信号源（EDF 文件 / 手动 / Xmuse OSC / 模拟心率）；Xmuse 默认同时监听 UDP 7000/8000
- 提供无设备试玩、EDF 回放验证、手动模拟校准、模型评估与实时监视
- 普通用户无需使用

### 3.6 成长系统（积分 / 签到 / 成就 / 商城 / 装扮）
- **积分 = 表现分按 30:1 折算**（有得分时至少 1 积分）：每局结束后一次性入账（开发者的调试入口不计分）；表现分与商城积分分离，历史积分不清空；积分只保存在本机浏览器
- **每日签到**：每天可领 2 积分，按本机时间 0 点刷新
- **成就**：共 15 枚，分为池塘小卫士（首次校准）、专注小达人 I–IV（单局 1/3/5/10 分钟）、青蛙博士 I–V（累计 30/60/150/300/600 分钟）、池塘守护神 I–V（连续打卡 3/5/7/15/30 天）
- **商城**：用积分购买装扮（5–18 积分）；成就专属装扮不出售，只能靠对应成就解锁
- **装扮**：分「图鉴 / 装扮 / 商城」三页；可搭配肤色、头饰、面饰、手持等，同一类别同时只穿一件；图鉴可查看全部外观、获取途径与获得时间
- 清空浏览器缓存会同时清空积分、签到、成就与装扮，且无法恢复

### 3.7 背景音乐（可选）
- 全站左下角黑胶唱片机：唱臂落下 = 播放，抬起 = 暂停并保留进度，左右箭头切歌
- 播放曲目与进度跨页面保留
- 服务端代理网易云公开歌单：`GET /api/music/playlist`、`GET /api/music/url/{track_id}`
- 未登录只能获取歌单前 10 首；登录后可取全量（`NCM_COOKIE` 环境变量或 `data/music_cookie.txt`）
- 不使用音乐时不会产生任何联网请求，也不影响游戏

## 5. 常见问题（FAQ）

**Q：为什么需要 EDF 数据？没有设备能玩吗？**
能。默认 `replay` 源回放本机配对 EDF 样本，无需硬件；也可以在开发者模式选「无设备试玩」。

**Q：我的脑电数据会传到云端/厂商吗？**
不会。第 6 节给出代码级证据：脑电链路无外网调用、无外链。Xmuse 通过本机 OSC/UDP 回环传输；心率通过本机 `hrd` 读取。仅可选背景音乐会访问网易云，且不携带脑电数据。

**Q：Xmuse 连上了但游戏一直提示未收到数据？**
1) 确认 Xmuse Direct/Lab 已连接设备；2) OSC 输出目标填 `127.0.0.1`，端口与页面一致（默认 7000/8000）；3) 前缀留空或填端口号（地址变为 `/eeg` 或 `/8000/eeg`）；4) 用 `python scripts/xmuse_osc_probe.py` 抓包确认地址。

**Q：UDP 7000/8000 被占用怎么办？**
关闭占用端口的程序，或在页面/环境变量 `XMUSE_OSC_PORTS` 中改用其它端口（如 `7100`）。

**Q：为什么心率选项是灰的？**
心率辅助与仅心率模式只在 macOS 上可用（依赖 `hrd` 读取 AirPods Pro 3）。Windows/Linux 上会显示不可用原因，脑电玩法和回放不受影响。

**Q：积分 / 成就 / 装扮会同步到别的设备吗？**
不会，也不会上传。它们只保存在当前浏览器 `localStorage`。换浏览器、清缓存或无痕模式会得到一份全新的本地进度。

**Q：报告导出为什么是空的 / 某个格式不可用？**
导出在本机服务端生成；PDF/Excel/Word 依赖 `reportlab` / `openpyxl` / `python-docx`。缺少依赖时只有对应格式提示不可用。若页面还没有有效帧，会提示数据不足。

**Q：会话记录存在哪、怎么删？**
`outputs/sessions/*.json`。删除该目录即全部清除；浏览器本地的积分/成就需在浏览器设置里清除站点数据。

**Q：服务端口被占用怎么办？**
换端口：`uvicorn app.server:app --host 127.0.0.1 --port 9000`，浏览器访问 `http://127.0.0.1:9000`。

**Q：接入 Xmuse 后，是否需要联网？**
不需要。蓝牙 + OSC/UDP 均为本机连接。

## 6. 数据与隐私保障（重要）

### 6.1 隐私承诺（有代码依据）

1. **前端零外部静态资源**：所有页面无 CDN、无字体服务、无统计脚本
2. **脑电数据处理链路零外网**：`sources.py` / `features.py` / `focus_engine.py` / `heart.py` 不含任何出站调用；服务只监听 `127.0.0.1`
3. **接口全相对路径**：`api.js` 用 `/api/...` 相对地址，只会连到本地 `127.0.0.1:8000`
4. **报告导出在本机完成**：`export.py` 由本地服务生成文件后直接下载，不经过第三方或云端
5. **成长系统不上传**：积分、签到、成就、装扮全部只写浏览器 `localStorage`，没有账号体系，也没有服务端接口
6. **唯一例外是可选背景音乐**：`app/music.py` 会访问 `music.163.com` 获取公开歌单与直链；只发送曲目/歌单 ID，**不发送任何脑电、会话或个人信息**。不播放音乐时不触发该请求

→ **不使用背景音乐时，应用可以完全断网运行**，脑电数据没有任何离开本机的通道。

### 6.2 数据都存哪（全部在本机）

| 数据 | 位置 | 说明 |
|---|---|---|
| EDF 脑电样本 | `data/eegmat/*.edf` | PhysioNet 公开数据集本地副本（回放源） |
| 预处理中间数据 | `data/processed/` | 训练用 |
| 模型文件 | `outputs/models/LogisticRegression.joblib` | 本地训练产物 |
| 会话记录 | `outputs/sessions/{会话id}.json` | 每次会话结束后落盘（专注度时序、起跳事件等） |
| 训练报告 | `outputs/train_report.md` | 模型指标 |
| 校准基线 | 浏览器 `localStorage: bf-calib` | 1 小时有效，不上传 |
| 成长数据 | `localStorage: bf-wallet / bf-checkin / bf-achievements / bf-owned / bf-outfit` | 积分、签到、成就、装扮 |
| 视觉与音频偏好 | `localStorage: bf-sky-mode / bf-music-* / bf-pond-audio` | 天空模式、音乐状态、音量 |
| 音乐登录凭据（可选） | `data/music_cookie.txt` | 网易云 cookie，已在 `.gitignore` 中忽略 |
| 运行日志 | 终端 / `.deepworks/tmp/server.log`（开发期） | 无脑电原始数据 |

### 6.3 本地处理链路

```
[EDF 本地文件 / 滑块 / Xmuse蓝牙→Direct→OSC/UDP / AirPods→hrd]
        ↓（全部在本机回环）
features 滤波 + Welch 功率谱 → 模型推理 / 频段指标 / 心率融合
        ↓
SSE 推送（127.0.0.1 回环）→ 浏览器渲染
        ↓
会话报告写入 outputs/sessions/*.json（本地）；导出文件由浏览器下载（本地）
```

**脑电数据处理没有任何一环经过公网。**

### 6.4 Xmuse / 心率模式的隐私说明

- Xmuse 设备 → 蓝牙 → 本机 Xmuse Direct/Lab 软件 → **OSC/UDP 均在本机回环（127.0.0.1）**
- 心率由本机 `hrd` 工具经蓝牙读取，数据不离开本机
- 原始脑电/心率仅在内存中参与特征计算，报告只存聚合后的专注度时序（`outputs/sessions/*.json`）
- 不会、也不需要把数据发往设备厂商云端

### 6.5 隐私最佳实践

- **断网运行**：不播放背景音乐时无需联网即可完整体验（唯一例外：首次下载 EDF 数据集需联网，一次性）
- **清理数据**：删除 `outputs/sessions/` 即可清空所有会话记录；删除 `data/eegmat/` 可移除数据集副本
- **清理成长数据**：浏览器设置中清除本站点数据（会同时重置积分、签到、成就、装扮）
- **清理音乐凭据**：删除 `data/music_cookie.txt` 或注销 `NCM_COOKIE` 环境变量
- **监听范围**：服务只监听 `127.0.0.1`（本机回环），局域网内其他设备无法访问
